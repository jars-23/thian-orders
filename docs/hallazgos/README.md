# Hallazgos

Un fichero por auditoría: `AAAA-MM-DD-auditoria.md` (solo lectura; cada corrección es después un encargo normal con [[plan-de-cambio]]).

## Formato
| Id | Severidad | Fichero:línea | Evidencia | Riesgo | Recomendación | Esfuerzo |
|---|---|---|---|---|---|---|
| H-01 | Crítica / Alta / Media / Baja | `src/…:123` | medido: comando o cita | qué puede pasar | qué hacer | S / M / L |

Ordenada por severidad. Ver también [[trampas]] y [[arquitectura]].
